Templates are larger starting points that you copy into your project and maintain
yourself. They are not npm package imports.

## Copy and adapt a template

1. Follow [Using components](../guides/setup.md) for package dependencies and provider setup.
2. Choose a template and download every source file listed on its page.
3. Save the files in your app and install the dependencies listed for that template.
4. Adapt the actions and navigation to your product.

Keep keyboard behavior, accessible names, focus visibility, responsive layouts,
and both themes when adapting a template.

Template pages include a complete example and the original component source.
For shared React Router link code, see [React Router link slots](../guides/router-link-slots.md).
