## Behavior and states

- Avatars can include presence badges to indicate the status of an associated person.
- Avatars can include activity rings to indicate when a person is currently collaborating in a shared activity.
- By default, avatars are static elements that don’t have states built in.
- If you include additional interactions to provide more context or information, be sure to author in states and keyboarding interactions.
